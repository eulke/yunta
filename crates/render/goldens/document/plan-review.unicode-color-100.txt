  Install packs in the user's Yunta state directory for use across projects

  ␛[2myou asked   ␛[0m add pack global instalation support, not only project level as today

  Add user-wide pack installation alongside project-local vendoring. A global pack lives under the
  existing YUNTA_HOME (or ~/.yunta) state root, so every project using that same user state can
  discover it. ␛[1myunta␛[0m ␛[1mpack␛[0m ␛[1madd␛[0m ␛[1m--global␛[0m installs there; local installs continue to use the repository
  tree. Resolution prefers a project-local pack when the same workflow is available locally, then
  falls back to global packs. Pack locks and list/remove operations remain scoped to the selected
  installation level.
