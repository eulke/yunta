# D40 — Idioma del código: inglés; documentos de diseño: español

Identificadores, comentarios, rustdoc, CLI, errores y commits en inglés — el
ecosistema aspiracional (packs compartidos, adapters de terceros) lo exige y
los términos del glosario mapean 1:1 (`Runner`, `Adapter`, `Pack`). Los docs
de diseño permanecen en español por ser del equipo.

Descartado: código en español (aísla el ecosistema) y docs en inglés (fricción
innecesaria hoy; traducir es evolución posible).
