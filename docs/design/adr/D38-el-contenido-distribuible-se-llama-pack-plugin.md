# D38 — El contenido distribuible se llama "pack"; "plugin" no existe en el vocabulario de Yunta

Razones: (a) "plugin" ya está tomado por las extensiones nativas de Claude
Code, con el que Yunta convive en el mismo flujo — ambigüedad garantizada; (b)
si algo mereciera el nombre son los executors (código que extiende el engine),
no un bundle declarativo; (c) un pack es contenido que corre sobre un runtime
que no modifica — familia de charts/módulos/collections, no de plugins.

Descartados: plugin (colisiones), kit (colisiona con ecosistema propio),
bundle (sin verbo natural), nombres temáticos (opacos; D28 aplica).
