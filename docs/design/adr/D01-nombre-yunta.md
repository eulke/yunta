# D01 — Nombre: Yunta

El arnés que une bueyes para tirar juntos: significado exacto (multi-agente
coordinado), identidad rioplatense, sin colisiones en el ecosistema.

Descartados: Talos, Fragua, Rienda, Tiro, Crisol. Verificar disponibilidad en
crates.io antes de publicar.
